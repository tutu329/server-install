二、内网服务器安装docker（【注意】内网服务器要和外网服务器的【Ubuntu 24.04、amd64】一致，如果版本或架构不同，需要在与内网匹配的联网 Ubuntu 环境中准备安装包，不能直接套用外网服务器的软件源。）
    1、先确认两边系统，并获取内网的软件安装清单。内外网服务器均执行：
        cat /etc/os-release
        dpkg --print-architecture
        例如，两边均为 Ubuntu 24.04、amd64。
        【注意】如果版本或架构不同，需要在与内网匹配的联网 Ubuntu 环境中准备安装包，不能直接套用外网服务器的软件源。
    2、内网服务器执行（这个文件记录内网已经安装的软件，用来判断还缺哪些依赖。）：
        cp /var/lib/dpkg/status ~/target-dpkg-status
    3、在外网服务器下载安装包
        1）创建目录
            mkdir -p ~/docker-offline/debs/partial
            cd ~/docker-offline
        2）把内网的 target-dpkg-status 文件复制到这个目录，使其路径为：
            ~/docker-offline/target-dpkg-status
        3）外网服务器已经配置过 Docker 软件源，直接更新索引：
            sudo apt-get update
        4）然后下载。以下命令沿用外网已经安装的 Docker、CLI、containerd 和 Compose 版本，并下载 Buildx：
            sudo apt-get \
              --download-only \
              --no-install-recommends \
              --no-remove \
              -o Dir::State::status="$PWD/target-dpkg-status" \
              -o Dir::Cache::archives="$PWD/debs" \
              install \
              "docker-ce=$(dpkg-query -W -f='${Version}' docker-ce)" \
              "docker-ce-cli=$(dpkg-query -W -f='${Version}' docker-ce-cli)" \
              "containerd.io=$(dpkg-query -W -f='${Version}' containerd.io)" \
              "docker-compose-plugin=$(dpkg-query -W -f='${Version}' docker-compose-plugin)" \
              docker-buildx-plugin

            （这条命令中：
            - --download-only：只下载，不安装，因此不会升级或重启外网 Docker。
            - Dir::State::status=...：按内网的软件安装清单计算依赖，避免因为外网已经安装过而漏下载。
            - Dir::Cache::archives=...：将下载的 .deb 放到 debs 目录。
            这些参数由 APT 支持。）
        5）下载成功后执行：
            ls -lh debs/*.deb
            tar -czf docker-offline-install.tar.gz debs
            sha256sum docker-offline-install.tar.gz > docker-offline-install.tar.gz.sha256
        6）把下面两个文件复制到内网：
            docker-offline-install.tar.gz
            docker-offline-install.tar.gz.sha256
    4、在内网服务器安装docker
        1）进入上述这两个文件所在的目录，校验：
            sha256sum -c docker-offline-install.tar.gz.sha256
        2）显示ok后：
            tar -xzf docker-offline-install.tar.gz
            sudo apt-get \
              --no-download \
              --no-install-recommends \
              --no-remove \
              install ./debs/*.deb
            （【注意】这里使用 APT 安装本地包，让它处理安装顺序和依赖；--no-download 禁止联网下载。若仍缺包，会报错，需要回外网补齐。）
        3）安装成功后，启动服务并设置开机启动：
            sudo systemctl enable --now docker
            sudo systemctl status docker --no-pager
            sudo docker version
            sudo docker compose version
            sudo docker ps

set -Eeuo pipefail

import json
from pathlib import Path
import sys

root, token, work = map(Path, sys.argv[1:])

data = token.read_bytes()
if hashlib.sha256(data).hexdigest() != expected:
    raise SystemExit('词表 SHA-256 校验失败，请重新下载官方 cl100k_base.tiktoken。')

cache = root / 'deploy/ocean_base/data-gym-cache'
cache.mkdir(parents=True, exist_ok=True)
cache.chmod(0o755)
destination = cache / key
if token.resolve() != destination.resolve():
    destination.write_bytes(data)
destination.chmod(0o644)

        'type': 'bind', 'source': str(cache), 'target': '/opt/tiktoken-cache',
        'read_only': True, 'bind': {'create_host_path': False},
    }],
}}}
(work / 'tiktoken.override.json').write_text(json.dumps(config, ensure_ascii=False))

import re
from pathlib import Path
import sys

source, destination, work = map(Path, sys.argv[1:])

required = ['oceanbase', 'redis', 'traefik', 'life-agent']
images = []
for name in required:
    service = services.get(name)
    if not service or not service.get('image'):
        raise SystemExit(f'Compose 中缺少服务或 image 配置：{name}')
    images.append(service['image'])

owner = str(services['life-agent'].get('user', ''))
if not re.fullmatch(r'[0-9]+:[0-9]+', owner):
    raise SystemExit('life-agent.user 必须是数字 UID:GID')

for service in services.values():
    service.pop('build', None)
    service['pull_policy'] = 'never'

destination.write_text(json.dumps(config, ensure_ascii=False))
(work / 'required-images.txt').write_text('\n'.join(images) + '\n')
(work / 'app-image.txt').write_text(services['life-agent']['image'])
(work / 'app-owner.txt').write_text(owner)

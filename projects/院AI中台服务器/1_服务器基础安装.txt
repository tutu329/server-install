1.5、硬盘空间和其他(把/扩展到2T)
    1）alias(~/.bashrc中增加)
        alias p='ps aux | grep -v "grep" | grep $1'
        alias s='systemctl list-unit-files | grep $1'
        alias d='du -sh .; df -h .'
    2）lsblk查看磁盘分区情况
        NAME                      MAJ:MIN RM  SIZE RO TYPE MOUNTPOINTS
        sr0                        11:0    1 1024M  1 rom
        vda                       253:0    0    2T  0 disk
        ├─vda1                    253:1    0    1M  0 part
        ├─vda2                    253:2    0    2G  0 part /boot
        └─vda3                    253:3    0    2T  0 part
          └─ubuntu--vg-ubuntu--lv 252:0    0  100G  0 lvm  /
    3）确认空闲空间
        sudo pvs
        sudo vgs
        sudo lvs
        df -hT /
    4）如果 ubuntu-vg 的 VFree 显示约 1.9T，则执行(正常情况下不需要重启):
        sudo lvextend -r -l +100%FREE /dev/ubuntu-vg/ubuntu-lv
            sudo：以管理员权限执行。
            lvextend：扩展 LVM 逻辑卷。
            -l +100%FREE：把 ubuntu-vg 中尚未分配的空间全部加入该逻辑卷。
            -r：扩展逻辑卷后，自动同步扩展里面的文件系统。
            /dev/ubuntu-vg/ubuntu-lv：当前挂载在 / 的根逻辑卷。
    5）核实/是否已经扩容到了2T
        lsblk
            NAME                      MAJ:MIN RM  SIZE RO TYPE MOUNTPOINTS
            sr0                        11:0    1 1024M  1 rom
            vda                       253:0    0    2T  0 disk
            ├─vda1                    253:1    0    1M  0 part
            ├─vda2                    253:2    0    2G  0 part /boot
            └─vda3                    253:3    0    2T  0 part
              └─ubuntu--vg-ubuntu--lv 252:0    0    2T  0 lvm  /

7、安装docker(生产环境中不要用非root账户运行docker)
    1)安装必要的证书并允许apt包管理器使用以下命令通过https使用存储库: sudo apt install apt-transport-https ca-certificates curl software-properties-common gnupg lsb-release
    2)添加Docker的官方GPG密钥: curl -fsSL https://download.docker.com/linux/ubuntu/gpg | sudo gpg --dearmor -o /usr/share/keyrings/docker-archive-keyring.gpg
    3)添加阿里的镜像源GPG密钥
        curl -fsSL https://mirrors.aliyun.com/docker-ce/linux/ubuntu/gpg | sudo gpg --dearmor -o /usr/share/keyrings/docker-archive-keyring.gpg
        echo "deb [arch=amd64 signed-by=/usr/share/keyrings/docker-archive-keyring.gpg] https://mirrors.aliyun.com/docker-ce/linux/ubuntu $(lsb_release -cs) stable" | sudo tee /etc/apt/sources.list.d/docker.list > /dev/null

    4)添加Docker官方库: sudo echo "deb [arch=$(dpkg --print-architecture) signed-by=/usr/share/keyrings/docker-archive-keyring.gpg] https://download.docker.com/linux/ubuntu $(lsb_release -cs) stable" | sudo tee /etc/apt/sources.list.d/docker.list > /dev/null
    5)更新Ubuntu源列表: sudo apt update
    6)安装Docker: sudo apt install docker-ce docker-ce-cli containerd.io docker-compose-plugin
    7)验证docker状态: systemctl status docker
    8)配置使Docker服务开机自启动: sudo systemctl enable docker
    9)查看docker版本: sudo docker version
    10)docker测试:
        sudo docker run hello-world
            如果失败：
                修改Docker镜像加速器:
sudo tee /etc/docker/daemon.json <<EOF
{
  "registry-mirrors": [
    "https://docker.m.daocloud.io",
    "https://docker.mirrors.sjtug.sjtu.edu.cn",
    "https://dockerproxy.com"
  ]
}
EOF
                重启Docker:
                    sudo systemctl daemon-reload
                    sudo systemctl restart docker
                    sudo docker run hello-world

        sudo docker ps -a
    12)安装docker compose V2:
        sudo apt-get update
        sudo apt-get install docker-compose-plugin
        docker compose version
    或安装docker-compose V1:
        从github上下载docker-compose二进制文件安装:
            sudo curl -L "https://github.com/docker/compose/releases/download/v2.6.1/docker-compose-$(uname -s)-$(uname -m)" -o /usr/local/bin/docker-compose
        加可执行权限并移动到bin目录下:
            sudo chmod +x /usr/local/bin/docker-compose
            docker-compose -v
            此时docker-compose已经可用，可以在如Flowise/docker/下运行: sudo docker-compose up -d 或 sudo docker-compose stop
